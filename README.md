# wp3-d-clin-sop: Standard Operating Procedures (SOPs) in the DP-Next

This repository contains the general standard operating procedures (SOPs) for the clinical examinations in DP-Next. If necessary, the SOPs can be adjusted to the specific site of examination.

## Project files and folders

This list describes the default files are that are included from the
template.

- `.copier-answers.yml`: Contains the answers you gave when copying the
  project from the template.
  **You should not modify this file directly.**
- `.github/`: Contains GitHub-specific files, such as the workflow to
  build the website from the Markdown files.
- `_quarto.yml`: Quarto configuration file for the website, including
  settings for the website, such as the theme, navigation, and other
  options.
- `.gitignore`: This ignore file tells Git which files to not track.
  Unless you know what you are doing, it's best to not touch this
  file.
